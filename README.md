# uhbyeon's log_

변의혁(Ui-hyeok Byeon)의 개인 블로그입니다.

인공지능과 정보보안을 공부하며 읽은 논문, 살펴본 이슈, 개발 중에 배운 내용을 적습니다. 시간이 지나 다시 읽었을 때도 이해할 수 있도록, 문제의 배경과 해결 과정을 함께 남기려 합니다.

**[블로그 바로가기 → uhbyeon.github.io](https://uhbyeon.github.io/)**

## 메뉴 안내

| 메뉴 | 담는 내용 |
| --- | --- |
| [~/workspace](https://uhbyeon.github.io/) | 블로그 첫 화면과 최근 기록 |
| [all_logs](https://uhbyeon.github.io/posts.html) | 아래 네 분류의 글을 한곳에서 보기 |

| ↳ [papers_security](https://uhbyeon.github.io/papers-security.html) | 정보보안 논문에서 다루는 위협과 분석·대응 방법 |
| ↳ [issues](https://uhbyeon.github.io/issues.html) | 관심 있게 살펴본 기술·보안 소식과 그 배경 |

`all_logs`에서는 네 분류를 함께 읽거나 원하는 분류만 골라 볼 수 있습니다. 개발 메모는 `dev_notes`에 따로 모읍니다.

논문을 읽을 때는 무엇을 해결하려 했는지, 어떤 조건에서 결과를 얻었는지부터 살펴보려고 합니다. 이해한 내용과 아직 확인하지 못한 부분을 구분해서 적고, 잘못 적은 내용은 확인하는 대로 고치겠습니다.
